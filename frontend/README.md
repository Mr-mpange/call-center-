# MPANGE AI Call Center

An AI-assisted contact center dashboard with call routing, queue management, analytics, and an interactive IVR flow builder.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
